This post is a draft, so it only appears when you run `npm run dev`. Use it as a reference for what posts can contain.

## Frontmatter

```yaml
---
title: Required. The post title
description: Required. One or two sentences, used in lists, RSS and social cards
date: 2026-11-01
updated: 2026-11-05   # optional
tags: [nextjs, security]
draft: true            # optional, hides the post in production
---
```

The filename is the URL: `content/posts/my-post.mdx` becomes `/posts/my-post`.

## Code

Fenced code blocks are highlighted at build time, with a light and a dark theme. Add a title and highlight lines:

```ts title="example.ts" {2}
export function greet(name: string) {
  return `Hello, ${name}`;
}
```
